# Bluebird（青鸟）

一个 Windows 桌面邮件客户端，国内和国外邮箱都能用。基于 Electron + React + TypeScript。

当前版本 0.3，已经可以日常收发邮件：

- 添加账号：QQ、163、126、yeah.net、腾讯企业邮、网易企业邮、阿里邮箱、新浪、搜狐、139、iCloud、Yahoo 内置了服务器设置；其他邮箱输入地址后会自动识别（查 MX 记录和 Thunderbird 公开数据库），托管在腾讯/网易/阿里/Google/微软的企业域名邮箱也能识别出来
- Gmail、Outlook 用浏览器登录（OAuth），Gmail 也可以用应用专用密码
- 代理：设置里填本机代理软件的地址，每个账号单独选择走不走代理（比如 Gmail 走代理、QQ 直连）
- 「所有收件箱」：多个邮箱的新邮件按时间合在一起看，每封邮件用小圆点标出属于哪个账号
- 邮件列表按今天/昨天/最近一周分组，显示正文摘要；鼠标悬停直接归档、标记、加星、删除
- 读信页底部快速回复，不用打开写信窗口
- 无边框窗口，界面一直铺到标题栏
- 界面：左侧窄图标栏；整屏宽的单行邮件列表，点开后整屏阅读（也可以在「设置 → 外观」切回左右分栏）；启动时的主屏
- 聚焦列表：收件箱默认只列真人来信，通知和订阅各自折叠成一行
- 本地缓存：启动和切换文件夹先显示上次的内容，再在后台更新；断网时也能看已缓存的邮件
- 草稿自动保存：写信时每隔几秒存到本机，关掉窗口不会丢，点图标栏的草稿继续写
- 智能收件箱：自动把邮件分成「个人 / 通知 / 订阅」，可以按类别查看；可以设置只对真人来信弹通知
- 置顶、稍后处理（到时间放回收件箱并提醒）、重要发件人、屏蔽发件人
- 定时发送、邮件模板、快捷回复
- 命令中心（Ctrl+K）：输入几个字执行操作或跳转文件夹
- 文件夹右键菜单：全部标为已读/未读、清空已删除和垃圾邮件
- 多选和批量操作：点头像勾选，Ctrl+点击多选，Shift+点击连选，Ctrl+A 全选；批量标为已读/未读、加星、归档、移动、删除；右键菜单；一键「全部标为已读」
- 设置：外观（浅色/深色/跟随系统）、关闭后留在托盘、开机启动、默认发件账号、打开时是否标为已读、自动显示图片、列表摘要和密度、删除确认、签名、字号、通知声音和内容、免打扰时段、代理测试
- 文件夹列表和未读数、滚动自动加载更早的邮件、搜索
- 读信：HTML 邮件在沙箱里显示，默认拦截远程图片（防追踪），可以一键显示；附件打开和保存
- 写信、回复、全部回复、转发（带原附件）；简单的富文本格式；添加附件（也可以直接把文件拖进写信窗口）
- 星标、标为未读、归档、删除（移到「已删除」）
- 新邮件实时推送（IMAP IDLE）+ Windows 系统通知；电脑睡眠唤醒后自动重连
- 浅色/深色跟随系统
- 密码和令牌用 Windows 系统加密（DPAPI）保存在本机，不会上传到任何地方

## 开始使用

### 1. 安装 Node.js

到 <https://nodejs.org> 下载 **22 LTS** 版本安装（一路下一步即可）。装完在 PowerShell 里运行 `node -v`，能看到版本号就行。

### 2. 安装依赖

在项目文件夹里打开 PowerShell（文件夹空白处按住 Shift 右键 →「在此处打开 PowerShell 窗口」），运行：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
npm install --registry=https://registry.npmmirror.com
```

前两行让 Electron 本体（约 100 MB）从国内镜像下载，第三行让依赖包也走国内镜像。如果你在国外，直接运行 `npm install` 即可。

### 3. 启动

```powershell
npm run dev
```

会弹出 Bluebird 窗口。开发模式下改了界面代码会自动刷新。

### 4. 打包成安装程序

先关闭正在运行的 Bluebird，然后双击项目文件夹里的 `打包安装程序.bat`。第一次需要下载打包工具，大约 3 到 10 分钟。完成后会自动打开 `dist` 文件夹，里面的 `Bluebird Setup 版本号.exe` 就是安装程序。安装前先关闭正在运行的 Bluebird。

安装后可以从开始菜单或桌面图标启动，不再需要黑色窗口；「开机自动启动」也是安装版才生效。安装版和开发运行方式用的是同一份账号和设置。

如果打包失败，日志在项目文件夹的 `build.log` 里。常见原因是「无法创建符号链接」：在 Windows 设置里搜索并开启「开发者模式」，再运行一次。

## 添加国内邮箱

国内邮箱都要先在网页版里开启 IMAP/SMTP，并且用**授权码**登录，不能用网页登录密码：

- **QQ 邮箱**：网页版 → 设置 → 账号（新版叫「账号与安全」）→ 开启 IMAP/SMTP 服务 → 按提示用手机验证后生成授权码
- **163 / 126 邮箱**：网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP 服务 → 获取授权码
- **腾讯企业邮**：开启了安全登录时，需要在网页版「设置 → 客户端设置」里生成客户端专用密码

在 Bluebird 里点「添加邮箱」，选对应的邮箱，填地址和授权码即可。

## 配置 Gmail / Outlook 浏览器登录

浏览器登录需要你自己注册一个应用，拿到 Client ID 填到「设置 → 浏览器登录」里。只需要做一次。

### Google（Gmail）

1. 打开 <https://console.cloud.google.com>，新建一个项目（名字随便）
2. 在「API 和服务 → 库」里搜索 **Gmail API** 并启用
3. 打开 **Google Auth Platform**（OAuth 同意屏幕）：
   - 品牌塑造：填应用名称（比如 Bluebird）和你的邮箱
   - 目标对象：选「外部」
   - 数据访问：添加范围 `https://mail.google.com/`
4. 在「客户端」里新建 OAuth 客户端，**应用类型选「桌面应用」**，创建后复制 **客户端 ID** 和 **客户端密钥**
5. 回到「目标对象」，把发布状态改为 **「正式版」**。不改的话停留在「测试」状态，登录每 7 天就会失效

登录时 Google 会提示「Google 尚未验证此应用」，点「高级」→「转至 Bluebird（不安全）」即可。这是因为应用没有提交 Google 审核，自己用没有问题（未审核的应用最多 100 个账号使用）。

不想注册应用的话，也可以给 Google 账号开启两步验证，然后在「安全性 → 应用专用密码」生成一个 16 位密码，在 Bluebird 里选 Gmail →「改用应用专用密码登录」。

### Microsoft（Outlook / Hotmail / Live）

微软个人邮箱已经不支持密码直接登录 IMAP，只能用浏览器登录。

1. 打开 <https://entra.microsoft.com>（或 Azure 门户），进入「应用注册」→「新注册」
2. 支持的账户类型选 **「任何组织目录中的账户和个人 Microsoft 账户」**
3. 重定向 URI：平台选 **「公共客户端/本机（移动和桌面）」**，地址填 `http://localhost`
4. 注册后在概述页复制 **应用程序（客户端）ID**
5. （建议）在「API 权限」里添加 Office 365 Exchange Online 的委托权限 `IMAP.AccessAsUser.All` 和 `SMTP.Send`

把客户端 ID 填到「设置 → 浏览器登录 → Microsoft Client ID」，保存后就能添加 Outlook 账号。

### 在国内使用

Gmail 和 Outlook 在国内需要代理：

1. 「设置 → 代理」里勾选启用，填你代理软件的本地地址和端口。常见默认值：Clash 系列 `127.0.0.1:7890`（SOCKS5/HTTP 都行），v2rayN 的 SOCKS5 是 `10808`、HTTP 是 `10809`
2. Gmail/Outlook 账号默认就勾选了「通过代理连接」，国内邮箱默认直连
3. 浏览器登录那一步是在你的系统浏览器里完成的，浏览器本身也需要能打开 Google

## 数据存在哪里

`%APPDATA%\Bluebird\` 下：`config.json` 是账号和设置，`secrets.json` 是加密后的授权码和令牌。`state.json` 是置顶、稍后处理、发件人名单、模板和定时发送队列（这些只保存在本机，不会同步到邮箱服务器）。删除账号会同时删掉对应的密钥。`cache\` 是本地缓存（文件夹列表、每个文件夹最近一页邮件、正文摘要、最近打开过的邮件），用来加快打开速度，可以在「设置 → 通用」里清空。这几个 JSON 文件各有一份 `.bak` 备份，正式文件损坏时会自动用备份恢复。安装版的运行日志在 `bluebird.log`。卸载程序不会删除这个文件夹。

## 备份与恢复（换电脑不用重新登录）

账号和登录信息默认只在本机。想换电脑后直接恢复，在「设置 → 备份与恢复」里：

1. 选一个存放备份的文件夹，建议选云盘的同步目录（OneDrive、坚果云、百度网盘同步空间等）。
2. 设一个备份密码（至少 6 位），开启自动备份。之后每次改动都会自动更新文件夹里的 `Bluebird 备份.bbk`。
3. 新电脑上装好 Bluebird，等云盘把这个文件同步下来，在欢迎页点「从备份恢复」（或「设置 → 备份与恢复」），选中文件、输入密码即可。

备份文件用你的密码加密（scrypt + AES-256-GCM），里面有各邮箱的授权码和登录令牌，所以密码要设得别人猜不到；忘了密码这份备份就打不开。主屏的自定义背景图和本地缓存不在备份里。两台电脑同时使用时，备份文件以最后一次保存的为准。

## 项目结构

```
src/
  main/                 主进程（Node.js 环境）
    index.ts            窗口、IPC 接口、新邮件通知
    accounts.ts         添加/修改/删除账号
    store.ts            配置和加密密钥的读写
    presets.ts          各邮箱服务器预设、自动识别
    oauth.ts            Gmail/Outlook 浏览器登录和令牌刷新
    net.ts              HTTP 请求（可走代理）
    mail/
      imap.ts           IMAP 连接管理、断线重连、IDLE 监听
      service.ts        文件夹、列表、读信、标记、删除、搜索、附件
      smtp.ts           发信、存到已发送
      errors.ts         把错误翻译成中文提示
  preload/index.ts      暴露给界面的有限接口
  renderer/             界面（React）
    src/App.tsx         状态管理和快捷键
    src/components/     侧边栏、邮件列表、读信、写信、添加账号、设置
  shared/types.ts       主进程和界面共用的类型
```

常用命令：`npm run dev` 开发运行，`npm run typecheck` 类型检查，`npm run dist:win` 打包（国内网络请用 `打包安装程序.bat`，它会设置好下载镜像）。

## 已知限制

- 「所有收件箱」是各账号分别取一页再按时间合并的，往下翻时会逐步补齐更早的邮件
- 搜索使用的是服务器端搜索，部分国内邮箱对中文搜索支持不好
- QQ 邮箱发信后是否自动存到「已发送」取决于网页版设置；如果发出的信在「已发送」里看不到，在「设置 → 邮箱账号」里勾选「发送后存到已发送」
